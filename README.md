# متجر الحومة (Flutter)

تطبيق Flutter بسيط بواجهة عربية لعرض منتجات محلية مع صفحة تفاصيل لكل منتج.

## المميزات
- واجهة عربية واتجاه RTL.
- صفحة رئيسية تعرض قائمة منتجات.
- صفحة تفاصيل لكل منتج.
- زر **اتصل بالبائع** (حاليًا رسالة تجريبية عبر SnackBar).

## التشغيل
> يتطلب Flutter SDK.

```bash
flutter pub get
flutter run
```

## الاختبار
```bash
flutter test
```
